# SILLOG Homebrew tap

[SILLOG](https://github.com/sillog-admin/SILLOG)을 Homebrew로 설치합니다.

```bash
brew install --cask sillog-admin/tap/sillog
```

`Casks/sillog.rb`의 버전과 sha256은 SILLOG 저장소의 CI가 main 릴리스마다 고칩니다. 직접 고치지 않습니다.

The version and sha256 in `Casks/sillog.rb` are updated by SILLOG's CI on every main release, so don't edit them by hand.
